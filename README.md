# 🧠 Dr. Öğr. Üyesi Ekrem Yalçın — Resmi Web Sitesi

Beyin, Omurilik ve Sinir Cerrahisi Uzmanı **Dr. Öğr. Üyesi Ekrem Yalçın** için geliştirilmiş kurumsal, mobil uyumlu ve SEO odaklı resmi web sitesi.

🔗 **Canlı Proje:** [drekremyalcin.com.tr](https://www.drekremyalcin.com.tr)

---

### 🚀 Özellikler
* **Modern Arayüz & UX:** Hasta odaklı, sade ve hızlı gezinme deneyimi
* **%100 Mobil Uyumlu:** Tüm cihazlarla tam uyumlu (Responsive) tasarım
* **İleri Seviye SEO:** Google Search Console, Schema meta etiketleri ve yerel arama optimizasyonu
* **Hızlı Performans:** Optimize edilmiş modern bileşen mimarisi

---

### 🛠️ Kullanılan Teknolojiler
* **Framework:** React / TypeScript
* **Stil & Tasarım:** Tailwind CSS
* **Build Tool:** Vite
* **Dağıtım (Deployment):** Vercel
